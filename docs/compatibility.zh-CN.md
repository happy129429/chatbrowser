# 兼容与合规说明

[English](compatibility.md)

本项目是非官方的本地对话归档浏览器。它只读取用户主动选择的导出文件，在本地整理和展示，并可导出转换后的副本；导入过程不会上传数据。

## 实现边界

- 解析器基于用户提供的导出数据、公开格式信息和可观察行为独立实现。
- 不把厂商应用代码、打包资源、CSS 或界面文案复制进本项目。
- 为实现互操作，可以使用字段名、JSON 路径、时间戳等功能性事实；面向用户的解释文字由本项目自行撰写，不复制厂商文案。
- 不使用私有 API、不抓取在线服务、不绕过访问控制。

## 数据边界

- 导入和导出都在浏览器或应用沙箱内本地完成。
- 只导入你有权处理的数据。导入他人的对话可能涉及他人隐私，请先确认授权。
- 测试使用合成或脱敏数据。真实导出、附件和账号标识不应提交到仓库。
- 对能够识别的账号级个人文件，导入器会跳过；组附加信息只保留产品需要的内容。

DeepSeek、ChatGPT/OpenAI、Claude/Anthropic、z.ai 等名称归各自权利人所有。本项目与这些公司无关联、未获赞助或背书；兼容性描述仅用于说明支持范围。

## 开源合规

- 本项目以 GPL-3.0-or-later 分发；上游 deepseek-ai/chat-demo 的 MIT 声明保留在 `LICENSE` 中。
- 第三方依赖保留各自的许可证。构建会生成 `THIRD_PARTY_NOTICES.txt`，随 Web 构建、桌面包和 Android 包分发，并可在应用内「关于」页面查看。
- 不加入许可证未知或不兼容的依赖，也不混入厂商专有代码；新增依赖需要检查许可证并重新生成通知。

## 贡献

不要提交厂商应用代码、复制的界面文案或资源，也不要提交真实用户导出。兼容性测试样例必须是合成或已脱敏数据。新增依赖或素材时，贡献者需要自行确认其许可证。
