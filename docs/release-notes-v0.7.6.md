# Release v0.7.6

组批量管理、Claude 父链修复与导出入口整理。

## 组批量管理

设置 → 数据管理 → 组批量管理：

- 多选组，支持全选、仅选普通组；默认组可导出/改色，也可作为合并目的地
- 默认组选中为源时，合并/删除置灰并显示保护提示
- 合并到已有组，或在目的地列表底部直接新建组；源组在成功后删除
- 合并组级附加信息（extras）：完全相同的条目去重，同标题不同内容追加来源组名
- 分别导出 / 合并导出，格式与「导出为…」一致；合并导出使用内存虚拟组，不修改原组
- 合并导出默认组名与文件名带本地日期和时分秒，如 `合并导出 2026-11-23 08-26-18.zip`
- 批量改色、批量删除（确认影响组/会话/extras 数量）
- 新建空白组
- 单组合并现在也会保留源组 extras

## Claude

- `parent_message_uuid` 按前 16 个字符（含连字符、忽略大小写）匹配，兼容截断或尾部不一致的导出
- 个别父节点缺失时按数组顺序接回前一条，避免整段会话变成并列根节点

## 导入 / 导出

- 文案统一为「导入 / 导出」：「打开归档」改为「导入归档」，「上传/下载」改为「导入/导出」
- 拖拽提示改为「或点击下方按钮」
- 导出格式命名为 `DeepSeek 兼容 ZIP` 与 `对话浏览器扩展 ZIP`
- DeepSeek 兼容 ZIP 标记为有损，并说明不保留分组、摘要、系统提示词、引用/思考状态
- 导出所有历史会话的小字标明格式与限制，并说明在本机生成、不会上传
- 组菜单移除独立的「解散」；合并到默认组即等价操作
